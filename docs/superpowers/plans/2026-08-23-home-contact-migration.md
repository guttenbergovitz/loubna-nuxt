# Home + Contact Content Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate homepage (options, features, image galleries) and the intro texts of the contact and book-a-call pages out of `@nuxtjs/i18n` JSON into `@nuxt/content` data collections so they are editable via Nuxt Studio.

**Architecture:** Hybrid — scenario-driven data goes to content collections; typography-controlled copy and form strings stay in i18n. Adds three new content collections (`galleryImages` single-locale, `homeOptions` + `homeFeatures` per-locale), extends the existing `singletons` collection's `page` enum with `contact` and `book-a-call`, extends the migration script, refactors three pages, and removes the migrated keys from i18n.

**Tech Stack:** Nuxt 4, @nuxt/content v3 (queryCollection, zod schema in `content.config.ts`), @nuxtjs/i18n v10, existing composable `app/composables/useContentByLocale.ts`.

## File Structure

**Create:**
- `content/gallery/*.yml` — 9 gallery images (6 `group: home` + 3 `group: secondary`), generated by script
- `content/home-options/{en,nb}/*.yml` — 3 options × 2 locales, generated by script
- `content/home-features/{en,nb}/*.yml` — 4 features × 2 locales, generated by script
- `content/singletons/{en,nb}/contact.yml`, `content/singletons/{en,nb}/book-a-call.yml` — generated by script

**Modify:**
- `content.config.ts` — add `galleryImages`, `homeOptions`, `homeFeatures` collections; extend `singletons.page` enum
- `scripts/migrate-i18n-to-content.mjs` — add the new collections + the two new singletons
- `app/pages/index.vue` — replace hardcoded gallery arrays + options/features i18n reads with content queries
- `app/pages/contact.vue` — read title/tagline/intro from `singletons` (page `contact`), gallery from `galleryImages`
- `app/pages/book-a-call.vue` — read title/tagline/process from `singletons` (page `book-a-call`), gallery from `galleryImages`
- `i18n/locales/en.json`, `i18n/locales/nb.json` — remove migrated keys

**Scope notes (stays in i18n):** `home.hero`, `home.intro`, `home.howToGet.*`, `home.alternative.*`, `home.whatMakesDifferent.*`, `home.cta.*`, `nav/footer`, `seo.*`, `thankYou.*`, all form strings, `partners.heading`, `contact.form.*`, `bookCall.form.*`. Hardcoded video IDs/embeds (`BunnyVideo`, `HomeVideoTwo`) also stay hardcoded.
